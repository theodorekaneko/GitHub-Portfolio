# Loss Cost Predictor

An interactive web application modeled around French Motor TPL (Third-Party Liability) insurance claims to predict potential claim costs.

## Live Demo
[Click to view live application](https://app-portfolio-emfvvtyaprrjkhemlawmvm.streamlit.app)

## Project Overview
This project uses data science and machine learning concepts to estimate insurance loss cost based on classifying driver variables, vehicle types, and historical claim attributes. It provides an intuitive user interface to interact with the underlying predictive models.

## Tech Stack
* **Frontend:** HTML, SCSS, JavaScript
* **Backend / Data Science:** Python (Pandas, NumPy, Scikit-Learn)

## Key Features
* **Interactive Dashboard:** Input parameters to see real-time cost predictions.
